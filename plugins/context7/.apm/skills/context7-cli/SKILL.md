# ctx7 CLI (doc search)

Fallback for fetching library documentation via the `ctx7` CLI when the Context7 MCP tools can't be used.
Requires `ctx7` in `PATH` (do not install it).

See [references/docs.md](references/docs.md) for the full `ctx7 library` / `ctx7 docs` workflow.
